# Pilotage du portefeuille et du laboratoire

Le Cockpit ouvre la navigation vers le compte, les coûts, la décision du jour, le laboratoire, la santé du système, les analyses de marché et le Forex. Les résultats du compte portent la date de leur source. Les montants du laboratoire sont fictifs. Une mesure manquante apparaît en gris.

Le cahier des charges validé le 27 novembre 2026 est conservé dans le dossier de travail du projet, au chemin `docs/specs/dashboard_refonte_pilotage_v1/BRIEF_CODEX.md`. Les six fichiers de référence sont dans le sous-dossier `maquette/`. Les maquettes contiennent des informations du compte et leur diffusion est privée.
